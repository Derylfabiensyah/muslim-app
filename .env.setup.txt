===============================================
   MUSLIM APP - ENVIRONMENT SETUP GUIDE
===============================================

⚠️  FIRST TIME SETUP - READ THIS FIRST! ⚠️

1. COPY TEMPLATE FILE
   -----------------
   Command:
   > copy .env.example .env

2. GET GEMINI API KEY
   ------------------
   Visit: https://makersuite.google.com/app/apikey
   - Login with Google Account
   - Click "Create API Key"
   - Copy the key

3. EDIT .env FILE
   --------------
   Open: .env
   Add your key:
   
   GEMINI_API_KEY=paste_your_key_here

4. INSTALL & RUN
   -------------
   > flutter pub get
   > flutter run

===============================================
   TROUBLESHOOTING
===============================================

❌ Error: "GEMINI_API_KEY tidak ditemukan"
   ✅ Solution:
      - Check if .env file exists
      - Check if GEMINI_API_KEY is set in .env
      - Restart app: flutter run

❌ Error: "Gagal load .env file"
   ✅ Solution:
      - Verify .env is in project root
      - Run: flutter clean
      - Run: flutter pub get
      - Try again: flutter run

❌ App shows error screen
   ✅ Solution:
      - Read error message carefully
      - Usually .env is missing or empty
      - Follow steps 1-3 above

===============================================
   SECURITY REMINDERS
===============================================

🔒 DO:
   ✅ Keep .env in .gitignore
   ✅ Never commit .env to Git
   ✅ Use different keys for dev/prod
   ✅ Rotate keys regularly

🚫 DON'T:
   ❌ Share API keys in chat/email
   ❌ Screenshot .env file
   ❌ Hardcode keys in source code
   ❌ Commit .env to repository
